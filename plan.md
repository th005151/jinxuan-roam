# Crypto Affiliate Website Plan

## Goal

Build a Taiwan-focused crypto affiliate content website that attracts users through SEO and social media, then converts them into exchange signups through referral links.

Primary monetization:
- Binance affiliate
- Bybit affiliate
- OKX affiliate
- Additional fintech / tool affiliate programs later

Target audience:
- Taiwan crypto beginners
- Users searching how to buy BTC/USDT in Taiwan
- Users searching exchange comparisons
- Users looking for signup rewards

---
